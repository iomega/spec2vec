Spec2Vec documentation
======================

**Spec2Vec** learns relationships between MS/MS fragment and neutral-loss
words using a Word2Vec model and compares spectra through their embeddings.

The upcoming compatibility release supports matchms 1.0 and retains support
for matchms 0.x. Gensim remains the training backend for this release.
